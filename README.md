# SCL Official Website V36

GitHub Pages deployment package for Shining Child Leaders School.

## GitHub Pages

1. Put `index.html` and `.nojekyll` in the repository root.
2. On GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

The site is a static HTML/CSS/JavaScript frontend. Production authentication, student records, payments, fee data, uploads, results, staff/vacancy management, and other private school data should use the Supabase backend rather than browser-only storage.
